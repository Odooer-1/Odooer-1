## 💡 Odoo Dev Tips

> 💡 Always use `_inherit` over `_name` when extending existing models
>
> 💡 Use `@api.depends` correctly — avoid unnecessary recomputation
>
> 💡 Write migration scripts for every version upgrade — never skip them
>
> 💡 Test your modules on both Community and Enterprise editions
>
> 💡 Use `sudo()` with caution — only when truly needed for security context
